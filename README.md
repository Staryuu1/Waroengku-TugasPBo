# WaroengKu – Tugas PBO

WaroengKu adalah aplikasi **Point of Sale (POS)** sederhana berbasis **Flutter** yang dibuat sebagai **tugas Pemrograman Berorientasi Objek (PBO)**.  
Aplikasi ini mendukung manajemen produk, kategori, transaksi, laporan, serta autentikasi pengguna dengan **database lokal (SQLite)**.

---

## ✨ Fitur Utama

- 🔐 Login & Register User
- 📦 Manajemen Produk
- 🗂️ Manajemen Kategori
- 🧾 Transaksi POS
- 📊 Laporan Penjualan
- 💾 Database lokal (SQLite)
- 📁 Backup data
- 🧱 Arsitektur berbasis Model–Service–Page

---

## 🛠️ Teknologi yang Digunakan

- **Flutter & Dart**
- **SQLite**
- Android, iOS, Web, Windows, macOS, Linux
- GitHub Actions (APK build)

---

## 🚀 Cara Menjalankan Project

### 1. Clone Repository

```bash
git clone https://github.com/Staryuu1/Waroengku-TugasPBo.git
cd Waroengku-TugasPBo
```

### 2. Install Dependency
```bash
flutter pub get
```

### 3. Jalankan Aplikasi
```bash
flutter run
```
